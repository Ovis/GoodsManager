確認の順番

  1. 初期アカウントを作成 → ログアウト → 誤った／正しいパスワードでログイン。入力した秘密は各操作後に消えます。
  2. 現在のパスワードで本人確認してパスキーを追加 → ログアウト → パスキーでログイン。OSのPIN・生体認証は手動で行ってください。
  3. パスキーの名前変更、本人確認方法をパスキーにした追加・削除、OS画面のキャンセル後のやり直しを確認。
  4. 2つのタブで同じ状態を取得 → 片方でIDまたは名前を変更 → もう片方から変更して412を確認。入力は残り、再取得まで古いETagを使います。
  5. 別ブラウザまたは別プロファイルでもログイン → 全端末ログアウト → 両方で再取得して未ログイン（401）を確認。通常の別タブは同じセッションです。
  6. 再ログイン → パスワード変更 → 両方の失効、旧パスワードの拒否と新パスワードでのログインを確認。

保持あり／なしの persistent と絶対期限は上部に表示します。5回失敗の5分停止は検証用アカウントで別途確認してください。localhost のこの画面はPC内だけの確認用です。
